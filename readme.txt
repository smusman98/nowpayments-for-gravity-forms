== How It Works ==

1. Customer fills out your Gravity Form
2. Plugin sends payment data securely to NOWPayments
3. Customer is redirected to hosted crypto checkout
4. Customer completes payment in selected cryptocurrency
5. Payment status is updated automatically via webhook/IPN

== External services ==

This plugin connects to the NOWPayments API to process cryptocurrency payments.

It sends payment/order details to NOWPayments when checkout is initiated.

== Installation ==

1. Install and activate **Gravity Forms**
2. Upload plugin to `/wp-content/plugins/nowpayments-for-gravity-forms`
3. Activate the plugin
4. Navigate to **Forms → Settings → NOWPayments**
5. Enter API credentials and IPN Secret
6. Configure Sandbox or Live Mode
7. Add a NOWPayments feed to your form
